# Glossary — EN / TR

Phase 2.4. Every row below is the **shipped** pair, read out of the source table
that owns it, not a translation proposed here. When a term is added to the
canvas it goes into that table first and into this file second; a term that
appears in one column only is a bug, and `audit/measure-display.mjs` fails the
run for it (`locale_leaks`, currently **0 across all 73 journeys in both
locales**).

## Node kinds — on the card

`CARD_TEXT` in `src/components/ui/JourneyCanvasNodes.tsx`.

| EN | TR | what it labels |
|---|---|---|
| Trigger | Tetikleyici | the one entry node; the journey starts here |
| Decision | Karar | a condition — a question with two or more branches |
| Wait | Bekleme | a pause until an event fires or the timeout runs out |
| Handoff | Devir | ownership passes to another journey or an external system |
| Outcome | Sonuç | a named state the journey reached and carries on from |
| Exit | Çıkış | the journey stops here |
| Internal | İç işlem | an action with no outward effect |
| Message | Mesaj | an action whose `execution` is `communication` |
| Human | İnsan | an action whose `execution` is `human` |
| External | Dış | a handoff whose target is outside the corpus |
| Internal *(handoff)* | İç | a handoff to another journey in the corpus |
| Channel selection | Kanal seçimi | the action that picks which channel a touch goes on |
| Primary | Öncelikli | the channel role tried first |
| Fallback | Yedek | the role tried when the primary does not apply |
| Entry | Giriş | the pin on the trigger's top edge (from `copy[lang]`, not `CARD_TEXT`) |

| EN | TR | added by |

**Represented canonical steps** is the contract that makes every collapse
reversible for the reader: a card that stands for more than one canonical node
lists all of them, in canonical order, with each one's id, kind and headline.

## Channels

`CHANNEL_LABEL` in `src/lib/journey-channels.ts`.

| EN | TR |
|---|---|
| Email | E-posta |
| Push | Push |
| SMS | SMS |
| In-app | Uygulama içi |
| WhatsApp | WhatsApp |
| Sales | Satış |
| Task | Görev |

Push, SMS and WhatsApp are the same word on both routes by design — they are
product names, not English. The locale lint's allowlist
(`ALLOW` in `audit/measure-display.mjs`) exists for exactly this, so that a
correct Turkish page is not flagged for containing "Push".

## Touch stages

`TOUCH_STAGE_TR` in `src/components/ui/JourneyCanvasNodes.tsx` — the largest
table in the localization layer, one row per `Touch.stage` value the customer
surface actually uses (closed set, generated by reading the corpus). The stage
key is always English in the canonical data, so the card's Turkish title has to
come from a table rather than from the key.

A stage outside that table falls through to the generic kind label, which is why
adding a new `stage` value to `orchestration.touches` means adding its row here
in the same change.

## Terms of art used in this audit

| EN | TR | meaning |
|---|---|---|
| canonical graph | kanonik graf | what `src/canonical/*.ts` authors; never modified by display work |
| display graph | görüntü grafi | what `buildDisplayGraph()` hands to the layout engine |
| collapse / absorb | sadeleştirme / birleştirme | drawing several canonical nodes as one card |
| bookkeeping node | kayıt düğümü | an internal action that only writes a journal row |
| implementation gate | teknik geçit | "may this go out?" — permission, deliverability, pressure cap |
| business decision | iş kararı | a question whose answer changes what the journey does |
| shared terminal | ortak sonlanma | an exit or handoff several branches point at |
| per-parent instance | ebeveyn başına kopya | that terminal drawn once beside each branch (`x.converted@c.state`) |

The distinction in rows 5 and 6 is the one this whole audit turns on: an
implementation gate may be collapsed, a business decision may not, and the
corpus's own signal for telling them apart is whether the short arm records a
reason before exiting.

## Rules

1. Canonical keys are never translated — node ids, event ids and config keys
   (`recovery.first_check`) read the same on both routes, the same rule the
   corpus already applies to ids.
2. No number on a page is typed by hand. Corpus counts are derived
   (`src/lib/public-corpus.ts`, `src/lib/canonical-view.ts`), and the library's
   stated size — 71 journeys / 21 categories — comes from `LIBRARY_JOURNEYS`.
3. A new user-facing word is added to its table in `src/`, in both languages, in
   the same commit. This file is the index of those tables, never a second
   source of truth.
