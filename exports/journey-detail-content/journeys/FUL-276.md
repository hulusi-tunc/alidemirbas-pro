## FUL-276 — Substitution Approval

- Canonical ID: `FUL-276`
- Slug: `substitution-offer`
- Display name: Substitution Approval
- Canonical name (chain form): Substitution required → offer alternative → accepted, declined or lapsed
- Source route: `/lab/customer-journeys/substitution-offer`
- Category: Orders, fulfillment, delivery & service completion
- Goal: recovery-retry
- Channels: email, sms
- Surface: customer (communicating)

**Purpose**: Put a defined alternative in front of the person the obligation was made to, with a real decline path and a stated deadline, so that nothing different is ever supplied on the assumption they would not have minded.

> Put a defined alternative in front of the person the obligation was made to, with a real decline path and a stated deadline, so that nothing different is ever supplied on the assumption they would not have minded.

### Suppressed when
- [canonical rule] Nothing different is supplied on the strength of silence. Only an explicit acceptance moves the obligation.
- [canonical rule] The decline path sits in the same message as the accept path and costs the same effort to take.
- [canonical rule] A decline is not a cancellation. The affected scope remains open and owed.
- [canonical rule] Scope already fulfilled is untouched. The offer covers only what the exception actually affects.
- [canonical rule] One reminder before the window closes, never two.

**Channel roles** (recommended default)

### Stops when
- [success] alternative accepted and confirmed (re-entry: a further exception on the same obligation is a new instance with its own offer)
- [failure] alternative declined, affected scope still owed (re-entry: a different alternative found later is a new offer)
- [timeout] offer lapsed undecided, affected scope still open (re-entry: a new alternative identified later starts a new offer)
- [handoff] Contactability Recalculation — a substitution offer that cannot be delivered on any permitted route before its window closes

### Reusable rule
A substitute is only a substitute if the person it was offered to could have said no.

### Entity (notes)
- the affected scope of the obligation and the single alternative offered against it
- The offer covers the affected scope only. Everything already fulfilled stays fulfilled, and a second exception on the same obligation is its own instance.

### Distinct from
- FUL-145 (Fulfillment exception → diagnose → recover, substitute or fail) — FUL-145 diagnoses the exception, scopes it and decides that a defined alternative exists. This journey is the offer put to the recipient, and it starts only once that decision has been taken.

### Guardrails
1. Nothing different is supplied on the strength of silence. Only an explicit acceptance moves the obligation.
2. The decline path sits in the same message as the accept path and costs the same effort to take.
3. A decline is not a cancellation. The affected scope remains open and owed.
4. Scope already fulfilled is untouched. The offer covers only what the exception actually affects.
5. One reminder before the window closes, never two.
